# 职业规划模板（结构规范）

Agent 按此结构撰写 `plan.md`。年限/城市/方向随用户回答参数化；默认 10 年三阶段。此文件是**结构规范**，不是占位符模板——每个章节都要按用户真实情况写内容。

## 固定章节

### 〇、规划总览
- 一句话定位（来自"能力定位合成"）
- 阶段总览表：阶段 / 时间 / 年龄 / 目标定位 / 核心主题

### 一、现状盘点（SWOT）
- 优势（S）、劣势（W）、机会（O）、威胁（T）
- 只使用简历与用户回答中的真实事实；机会/威胁来自宏观研究

### 二、宏观环境
- 政策要点（当前五年规划：数字经济、数据要素、人工智能+ 等）＋ 经济周期判断（如康波周期）
- 每条标注**来源 + 日期 + 不确定性**
- 附"对个人的含义"：宏观如何落到这个人的具体路径上

### 三、分阶段规划（默认起步/进阶/突破）
每阶段必须包含：
- 目标与定位
- 求职/发展策略（城市、公司选择、行业）
- 技能补强清单（可含表格：现状 → 目标 → 学习路径）
- 工作方法与成长动作
- **可验证的里程碑**（时间点 + 达成标志）
- **进阶期与突破期默认各给出 2–3 条可选路线（必做项）**：每条路线含契合点、前景、关键动作、与本人适配性；给出推荐路线与最迟选择时间点（如进阶期第 1 年并行探索、第 2 年收敛）

### 四、能力地图
- 技能分级表：能力 / 现在 / 3 年 / 5 年 / 10 年（年限随规划长度调整）

### 五、证书与学历规划
- 已有证书、可选证书、学历提升评估时点（如工作 3 年时评估非全日制硕士）

### 六、风险与应对
- 表格：风险 / 影响 / 应对（含 AI 替代、学历门槛、行业波动、年龄焦虑等通用风险，结合本人情况）

### 七、年度执行清单
- 逐年表格：年份 / 年龄 / 核心动作 / 达成标志（覆盖整个规划年限）

### 结语 + 复盘建议
- 建议每年固定时间结合行业变化复盘修订

## 写作要求
- 每阶段必须有可验证里程碑，禁止空话
- 量化只允许来自简历真实数据或合理推算（推算标注"预估"）
- 宏观部分必须有来源与日期，且注明经济周期判断是参考框架而非确定性预测
- 全文语言跟随简历/用户，默认中文
